Bulk Import (CSV)

Import students from a CSV file. Required columns in order: StudentID, FirstName, LastName, Grade. Optional 5th column: MiddleName. To also import a referral contact, add: ContactType, ContactFirstName, ContactLastName, ContactEmail (columns 6–9) — Type is always required, but name and email are each independently optional as long as at least one is present: a contact can be a full name with no email, an email with no name, or both together. A first name with no last name (or the reverse) isn't allowed — enter both or leave both blank. Contact Type must match one of the types configured on the General tab (not case-sensitive). A student with multiple contacts gets one row per contact, all sharing the same StudentID — only the first row for a given ID needs the student's name and grade filled in; every row after that for the same ID can leave those blank and just carry another contact. A student with no contact yet is a single row with the contact columns left blank. First row must be a header row — it will be skipped.

Reset Term Points

Resets all student point balances to the current Term Start Points value. Referral history is not deleted. Use this for a mid-year or new-term reset — for a full year-end reset with archiving, use "Start New Year" below.

Archive a Term's Referrals

Exports one term's referrals to a CSV, downloaded straight to this computer, then permanently removes just those rows from the Referrals sheet. Student point balances are not changed — this only trims the detailed log, it doesn't undo anything those referrals already affected. Lowest-risk right after that term's points have already been reset above, since at that point the archived rows have no remaining connection to any live balance — but this works correctly at any time.

Start New Year

Archives all Referrals, Students, and Parent Contacts to a CSV file, downloaded straight to this computer, then permanently clears those three sheets so the school can start fresh. This does not touch Config, Infractions, or Staff — those aren't annual data. After resetting, re-import next year's roster from the Students tab above, and set new Term dates on the General tab.

Archiving and resetting — this can take a moment for a large school...
View a Previous Year's Referrals

Upload a CSV previously downloaded from "Start New Year" above to browse it. This is read-only and entirely in your browser — nothing is uploaded to the server or written back into the live Referrals sheet, it's just a way to look something up.
